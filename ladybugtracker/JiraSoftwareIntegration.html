Jira Software Integration

Jira Software is a powerful platform that combines issue collection and agile project management capabilities into a single application. Using Jira Software helps you plan and organize tasks, workflows, and reports for your agile team more efficiently.

Authentication

  1. In the plugin Open the login settings window. Then click “Create Token”
  2. You should be redirected to your Jira account page. Click “Create API token”
  3. Enter the token name and click “Create” to create a token
  4. Copy the token to the clipboard
  5. Enter your login and past token from the clipboard. Then click “Login”.

Setup project

The easiest way to set up a project is to use the "Bug Tracking" template.

  1. Go to create a project page
  2. Select “Software development” category
  3. Select “Bug tracking template
  4. Enter a project name and key and then click “Create Project”
  5. Add custom fields to the project. The fields should be named "Camera" and "Level" and should be of type "Short text". Adding new custom fields is not an easy process in Jira. Please read the Jira documentation to learn how to do that. These fields are mandatory to enable all the features of the plugin. https://confluence.atlassian.com/adminjiraserver/adding-custom-fields-1047552713.html
