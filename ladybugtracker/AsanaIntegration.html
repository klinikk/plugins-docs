Asana

Asana is a work management service. It organises work into workspaces, and each workspace into projects made of tasks; a project can be divided into sections, and a task can carry custom fields, subtasks, comments and attachments. LadyBug Tracker reports bugs as tasks in a single Asana project.

Asana is free for up to 10 users.

Authentication

Asana uses personal access tokens. In the login window enter:

  • Token — a personal access token from your Asana account.

To generate one, open My Settings > Apps > Developer apps in Asana (https://app.asana.com/0/my-apps) and create a personal access token. The token is shown once, so copy it straight into the Token field. The Create Token button in the login window opens that page for you.

No user name is asked for: the token identifies the account on its own.

The host address is fixed to Asana's own service and does not need changing.

Project setup (Asana service)

The plugin works against one Asana project inside one workspace. In the project settings:

  • Workspace selects the Asana workspace.
  • Project selects the project bugs are reported into. Archived projects are not offered.

You can point the plugin at a project you already have, or let it create one for you. A project created by the plugin comes divided into the sections a game team usually wants: General, Gameplay, Art, Sound, Level Design, UI and Other.

Where the position is stored

Every reported bug carries the level it was reported from and the camera it was reported at. Asana has no field of its own for these, so the plugin writes them into the task description, from where it reads them back. They travel with the description: editing it by hand in Asana can lose them, which is worth knowing before rewriting a description in the web interface.

Integration capabilities

  • Attachments can be added, viewed and deleted.
  • Comments can be added, viewed and deleted.
  • Subtasks are read and edited as a checklist. Asana gives a task one list of subtasks, so a bug has one checklist rather than several.
  • Custom fields already defined on the project are read and shown with the issue.

Known limitations

  • Issue history is not available. Asana's API does not expose the change log the way the plugin needs, so the History tab stays empty.
  • Status transitions are not offered. A task is either completed or it is not, and the plugin sets that directly rather than moving it through a workflow.
  • The free plan is limited to 10 users; project and storage limits are Asana's own.

Project setup (Unreal Engine)

Open Project Settings > Plugins > LadyBug Tracker and set:

  1. Provider — Asana.
  2. Change Login Settings — paste your personal access token.
  3. Workspace — pick your Asana workspace.
  4. Project — pick the project bugs should be reported to.

These settings are stored in Config/DefaultBugTracker.ini and can be shared with the team. Your token is stored separately, per user, and only when Remember Me is enabled.
