ClickUp

ClickUp is a project management and task tracking service. It organises work into workspaces (teams), spaces, folders and lists, and supports custom fields, checklists, comments and attachments. LadyBug Tracker reports bugs into a single ClickUp list.

This integration is currently in the beta stage.

Authentication

ClickUp uses personal API tokens. In the login window enter:

  • Username or Email — your ClickUp account.
  • API Token — a personal API token.

To generate the token, open Settings > Apps > API Token in ClickUp (https://app.clickup.com/settings/apps), click to generate it, and copy it into the API Token field. The Generate API Token button in the login window opens that page for you.

The host address is fixed to https://app.clickup.com and does not normally need changing.

Project setup (ClickUp service)

The plugin works against one ClickUp list. In the project settings:

  • Workspace selects the ClickUp team.
  • Project selects the list. Both folderless lists and lists inside a folder are found.

LadyBug Tracker stores the position a bug was reported from in two custom fields, which have to exist on the list:

  1. Open the list, then Custom Fields.
  2. Create a field named Level of type Text.
  3. Create a field named Camera of type Text.

The names must match exactly. If a field is missing, the plugin reports it when the project is verified, rather than failing silently.

Free plan behaviour

A free ClickUp workspace runs out of custom field usages. When the plugin detects a free plan — or when ClickUp refuses a custom field write — it writes the Level and Camera values into the task description instead, so reporting keeps working without a paid plan. Custom fields are still read, so tasks created earlier under a paid plan stay complete.

Because the values then live in the description, a task written that way can no longer have those values updated separately — they travel with the description.

Task status

The completed state of a task is derived from the ClickUp status type: a task counts as completed when its status type is done or closed. The list therefore needs at least one open status and at least one done or closed status.

Known limitations

  • The ClickUp API (v2) cannot delete attachments, so attachments can be added and viewed but not removed.
  • Issue history is not available.
  • Custom field usage on the free plan is limited — see Free plan behaviour above.

Project setup (Unreal Engine)

Open Project Settings > Plugins > LadyBug Tracker and set:

  1. Provider — ClickUp.
  2. Host — leave at https://app.clickup.com.
  3. Change Login Settings — enter your account and API token.
  4. Workspace — pick your ClickUp team.
  5. Project — pick the list bugs should be reported to.

These settings are stored in Config/DefaultBugTracker.ini and can be shared with the team. Your login and token are stored separately, per user, and only when Remember Me is enabled.
